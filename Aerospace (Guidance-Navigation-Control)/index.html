Control Architecture & Flight Logic

The ascent controller executes an initial vertical climb to achieve safe clearance velocity before introducing a pitch kick. Pitch angle decreases as a function of surface velocity and altitude, maintaining aerodynamic alignment to minimize angle of attack (α ≈ 0°) through high dynamic pressure regimes.

Ascent Guidance Logic (ascent_guidance.py)

import time
import krpc

# Establish telemetry connection
conn = krpc.connect(name='Ascent Guidance Controller')
vessel = conn.space_center.active_vessel

# Mission targets & parameters
TARGET_APOAPSIS = 80_000      # 80 km target orbit
PITCH_CUTOFF_ALT = 55_000     # Gravity turn terminal altitude
MAX_Q_LIMIT = 25_000          # Dynamic pressure threshold (Pa)

# Telemetry data streams
altitude = conn.add_stream(getattr, vessel.flight(), 'mean_altitude')
apoapsis = conn.add_stream(getattr, vessel.orbit, 'apoapsis_altitude')
dynamic_q = conn.add_stream(getattr, vessel.flight(), 'dynamic_pressure')

# Ignition & Liftoff
vessel.control.throttle = 1.0
vessel.auto_pilot.engage()
vessel.auto_pilot.target_pitch_and_heading(90, 90)
vessel.control.activate_next_stage()

# Ascent loop: Gravity turn & closed-loop Q_max throttle control
while apoapsis() < TARGET_APOAPSIS:
    alt = altitude()
    
    # Dynamic pitch kick profile
    if alt > 1000:
        progress = min(1.0, (alt - 1000) / (PITCH_CUTOFF_ALT - 1000))
        target_pitch = max(5.0, 90.0 * (1.0 - progress**0.5))
        vessel.auto_pilot.target_pitch_and_heading(target_pitch, 90)
    
    # Throttle modulation for aerodynamic load management
    if dynamic_q() > MAX_Q_LIMIT:
        vessel.control.throttle = 0.7
    else:
        vessel.control.throttle = 1.0
        
    time.sleep(0.1)

# Main Engine Cut-Off (MECO)
vessel.control.throttle = 0.0
vessel.auto_pilot.disengage()
print("MECO achieved. Sub-orbital trajectory verified.")
